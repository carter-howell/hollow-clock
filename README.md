# Hollow Clock

Status: Completed archive project

I built this 3D-printed magnetic clock with a Waveshare RP2040 Zero board, stepper motor, and stepper driver. It is an older engineering project that demonstrates mechanical fabrication, embedded control, and electromechanical motion.

![Hollow clock with magnetic hand](media/Clock.avif)

## Overview

I used hidden magnetic motion to move the clock hand while keeping the visible design clean. The build combines 3D-printed parts, a microcontroller, stepper control, and mechanical assembly.

## Hardware

- Controller: Waveshare RP2040 Zero
- Motor: stepper motor
- Driver: stepper motor driver
- Mechanical system: 3D-printed clock structure and magnetic hand mechanism

## What This Demonstrates

- RP2040-based embedded control
- Stepper motor actuation
- 3D-printed mechanical design
- Physical product assembly
- Early electromechanical project experience

## Status Notes
