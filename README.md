# Hollow Clock

Status: Completed archive project

This project is a 3D-printed magnetic clock built with a Waveshare RP2040 Zero board, stepper motor, and stepper driver. It is an older engineering project that demonstrates mechanical fabrication, embedded control, and electromechanical motion.

![Hollow clock with magnetic hand](media/Clock.avif)

## Overview

The hollow clock uses hidden magnetic motion to move the clock hand while keeping the visible design clean. It combines 3D-printed parts, a microcontroller, stepper control, and mechanical assembly.

## Hardware

- Controller: Waveshare RP2040 Zero
- Motor: stepper motor
- Driver: stepper motor driver
- Mechanical system: 3D-printed clock structure and magnetic hand mechanism

## What This Demonstrates

- RP2040-based embedded control
- Stepper motor actuation
- 3D-printed mechanical design
- Physical product assembly
- Early electromechanical project experience

## Status Notes

This is kept as an archive project. It is useful for showing long-term interest in building physical devices, but it should sit below newer PCB, robotics, embedded, and power-electronics work in Carter's public profile.
